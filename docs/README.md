## Historical milestone docs

The remaining `PHASE-*`, `C2.5`, `C3`, migration and parity documents are intentionally preserved as implementation evidence. They are **not current roadmap authority** unless explicitly linked above.

`archive/` is reserved for documents that are no longer active references but are still useful for historical recovery.

## Changelog policy

- Root [`../CHANGELOG.md`](../CHANGELOG.md) stays concise and current.
- Detailed milestone logs belong in [`../changelogs/`](../changelogs/README.md).
- Do not add new `CHANGELOG-*.md` files to the repository root.

## Acceptance language

- **CI GREEN** = automated validation only.
- **DEPLOYED CANDIDATE** = tested code is published.
- **REAL USER PASS** = deployed behavior was actually exercised and accepted.

Historical candidates never receive retroactive REAL USER PASS.
